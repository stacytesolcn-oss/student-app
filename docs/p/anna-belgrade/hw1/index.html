Girls' trip stories 🧳

Homework · 5 short tasks · about 25 minutes

Task 1

Read the thread

Maya asks for advice about her first girls' trip. Read her post and the replies. Then answer two questions.

Task 2

Find the phrase

Read the meaning in the black box. Find the highlighted phrase in the thread that means the same, and tap it.

Find 1 / 15
Task 3

-ed or -ing?

More comments from the same thread. Choose the right word.
-ed = how a person feels · -ing = the thing that makes you feel it

Task 4

Remember the phrases

Don't look at the thread. For each word you see the first and last letter, and a dash for each missing letter. Type the whole phrase, then tap Check.

Task 5

Say it with spend

Write each sentence again with spent. Keep the meaning. Then tap Check and compare.

… spent a lot of time + ___ing …
… spent the whole trip / weekend / day + ___ing …
